This repository contains my practical work from the [Yandex Machine Learning 2.0 Training](https://yandex.ru/yaintern/training/ml-training-october-2024), a program covering modern machine learning topics from representation learning and sequence models to LLMs, information retrieval, speech, VLMs, and multimodal systems.

## Result

- **6th place** in the [final ranking](https://yandex.ru/yaintern/training/results-ml-2).
- **Certificate:** [8 of 8 tasks solved](https://disk.yandex.ru/i/r-3gfmdyp_S8CA).

These results are the main reason I keep this repository as part of my public ML portfolio: it reflects both structured study and externally measured performance.

## What the training covered

- informative vector representations;
- generative and discriminative sequence models;
- attention and machine translation;
- large language models and LLM alignment;
- recommender systems;
- ranking, information retrieval, and NLP-adjacent tasks;
- audio processing, voice activation, biometrics, and speech recognition;
- vision-language models;
- multimodal and multi-agent systems.
